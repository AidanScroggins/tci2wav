tci2wav.

Trigger 2 .tci → velocity-named WAVs. Mono and stereo, V1/V2/Editor. Runs in your browser.

Source

Add .tci files or a whole folder. One file and a library both work the same way.

Jobs

Family and MIC come from the path. Edit either one to rename; the output path updates as you type.
